# Data and licensing boundaries

The authors' licensed AHA source records are not supplied. Requests for access
must go to AHA under the provider's terms, not to the authors for redistribution.
No commitment to supply permitted derived data within a fixed time is made here.

This code update includes author-owned analysis code and retains previously
published v137 outputs. New v143 aggregate summaries and finished figures remain
local, outside this repository update, pending the applicable license/NDA review.
Removing identifiers does not establish redistribution permission. The MIT
software license grants no rights to AHA records or third-party materials.

The following are intentionally excluded:

- Raw or enriched hospital records and survey extracts.
- Hospital-level fitted values, missing-status draws, and model caches.
- Block-group-level derived distance/proximity or map-value files.
- Geographic input layers and extraction caches.
- Reviewer responses, tracked Word documents, correspondence, and private notes.
- Database credentials, connection files, and machine-specific paths.

Finished maps can still convey derived information and require rights review.
The geometry used for figures is described by the scripts, but provenance and
reuse evidence for the original population GeoJSON must be retained and verified
before public release. This code update does not assert that a filename alone proves
its origin or licensing status.

Locally prepared aggregate source summaries do not constitute a complete
fine-grained map-source deposit. Resolve the journal's source-data requirement through permitted inputs
or an editor-approved restriction; do not promise material the authors cannot share.

Runtime directories and files are ignored as defense in depth. The final release
is built from an explicit checksum inventory, not by zipping the working directory.
Neither mechanism substitutes for a substantive rights review.
